# Background Music Directory

Place your `.mp3` audio files here!

### How it works:
- When a new image arrives, the video generator will randomly select one `.mp3` file from this folder to use as the background music for the Instagram Reel.
- The audio will be automatically trimmed to match the Reel duration (e.g., 8 seconds) and will smoothly fade out at the end.
- If multiple MP3 files are placed here, the system picks one at random for each new Reel.
- If no MP3 files are found, the Reel will be generated with a silent audio track.
